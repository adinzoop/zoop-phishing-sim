This was a controlled phishing simulation run by Zoop's security team. No real data was captured. You're safe — but let's make sure this doesn't happen with a real attack.

Red flags in that email

  • The sender address didn't end in @google.com — always check carefully.
  • The email created urgency ("suspicious activity", "limited access") to make you act fast.
  • Hovering over the link would have shown an unfamiliar domain — not accounts.google.com.
  • Real Google security emails never ask for your password via email.

What to do when you get a suspicious email

  • Do not click links — go directly to the site by typing the URL yourself.
  • Check the sender's actual email address (not just the display name).
  • Report the email using the "Report phishing" button in Gmail.
  • If you're unsure, forward it to security@zoop.one before acting.

How to check if a Google alert is real

Go to myaccount.google.com → Security → Recent security activity directly in your browser. Real alerts are listed there. Never use a link from an email to check this.
